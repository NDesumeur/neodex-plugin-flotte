# Flotte

La bataille navale contre l'ordinateur : cherche ses cinq navires et coule-les avant qu'il ne coule les tiens.

Deux grilles de 10 × 10, cinq navires chacun (5, 4, 3, 3 et 2 cases), placés au hasard sans se toucher. Chacun tire à son tour, et rejoue quand il touche. Le premier qui coule toute la flotte d'en face gagne.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Flotte → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
